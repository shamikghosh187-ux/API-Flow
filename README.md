# API-FLOW

A provider-agnostic AI API gateway with intelligent routing, provider failover, usage visibility, and an OpenAI-compatible interface.

## Status

Foundation in progress. The repository is being built around real server-side provider integrations, validated configuration, and observable request execution.

## Design

- Deep black and charcoal surfaces
- Crimson red as the primary accent
- Off-white typography and restrained motion

## Planned stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Supabase Auth and Postgres
- Zod validation
- Vercel deployment

## Security

Provider API keys must remain server-side. Never commit `.env` files or expose provider secrets in browser code.
